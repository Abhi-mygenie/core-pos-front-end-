CR-475 — Item Consumption Report 3 CHANGES
What the report will look like after CR-475 is implemented
① Menu Filter + Badge
A "Menu" dropdown appears in the filter bar. Default = All Menus. Each row shows a small grey badge under the dish name (e.g. "Normal", "Premium").
② New KPI Card
"Total Returned to Inv." is added as the 4th card. KPI strip now 2 rows of 3. Shows total returned-to-inventory quantity across all visible items.
③ Add-ons Drill-down
Inside expanded rows, a new "Add-ons" section appears. Each add-on shows its qty breakdown + 3 ingredient sub-tables. Hidden when dish has no add-ons.
