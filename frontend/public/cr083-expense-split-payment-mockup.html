CR-083 — Flow Summary
1. User adds expense line → single payment method (current behavior)
2. User clicks "Split" button → line expands, original method becomes Row 1
3. Row 2 auto-fills: same item, remainder amount, empty method dropdown
4. User picks second method (UPI, Unpaid, Cash Draw, etc.) and adjusts amounts
5. Validation: green bar when split sums match total · red bar when gap exists · Save disabled on mismatch
6. Cash Draw: shows available balance · red warning when amount exceeds balance
7. On Save → FE sends 2 detail lines to backend (same item, different methods) · backend accepts as-is
8. "Unpaid" lines tracked in reports · no settlement workflow (Phase 2)
