ASK 4 — CR-544: Cancel After Making Unpaid — Audit Event

Fraud pattern: Cashier marks order as "unpaid" (step 1, already tracked) → then cancels items or entire order (step 2) → pockets the difference.

Detection Logic

For each order in the date range that was made unpaid (make_unpaid event exists):

  • Get made_unpaid_at (timestamp of the make_unpaid action)
  • For each cancellation (item or order) on that order WHERE cancel_at > made_unpaid_at: emit audit event

New Event Type: cancel_after_unpaid

{
  "type": "cancel_after_unpaid",
  "order_id": "021544",
  "food_name": "Paneer Tikka",
  "amount": 200.00,
  "by": "Counter",
  "made_unpaid_at": "2026-11-16T14:30:00",
  "cancel_time": "2026-11-16T14:35:00",
  "scope": "item",
  "gap_minutes": 5
}

ASK 5 — CR-546: Discount After Bill Print — Audit Events (Apply & Remove)

Fraud pattern: Staff applies or removes a discount on an order after the bill has already been printed — indicating post-settlement manipulation.

Detection Logic

For each order where bill_printed_at IS NOT NULL:

  • If a discount was applied WHERE discount_applied_at > bill_printed_at → emit discount_apply_after_print
  • If a discount was removed WHERE discount_removed_at > bill_printed_at → emit discount_remove_after_print

New Event Type: discount_apply_after_print

  "type": "discount_apply_after_print",
