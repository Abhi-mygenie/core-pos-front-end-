NEW Channel count badge updates — the number shown next to "Dine-In 15" / "Room 13" reflects only the active tables when toggle is ON.
NEW Empty channels auto-hide — if a channel has zero active tables, the column disappears entirely (existing auto-hide behaviour already handles this).
