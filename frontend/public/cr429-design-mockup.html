What changes

CR-429 — Active First · Changes at a glance

NEW "Active First" pill — appears after a divider at the end of the Channel View filter row (same row as YTC / Preparing / Ready). Orange outline when ON, grey when OFF. Persists via localStorage.
NEW Occupied tables float to top — when ON, each channel column shows occupied/active tables first, available tables below. Sort within each group unchanged (label-numeric).
NEW "Available" section label (optional) — a subtle divider line between the occupied group and the available group so the boundary is clear.
UNCHANGED Available tables are still shown and clickable — nothing is hidden. Total table count in the channel header stays the same.
UNCHANGED Status View, order cards, search, column arrows, column counts — all untouched.
UNCHANGED Toggle OFF (default) = current label-numeric order with no occupied-first sort.
