What happens step by step after a new version is deployed
1
New version deployed
You push a new build to production. The new service worker downloads in the background silently.
Browser + PWA
2
New SW waits
Instead of activating immediately, the new worker sits in the "waiting" lane until the user gives the go-ahead.
After BUG-621 fix
3
Banner appears
The app detects the waiting worker. The black bar slides up from the bottom with a 10-second countdown ring.
Browser + PWA
4a
User clicks "Reload now"
App sends a signal to the waiting worker: "go ahead." Worker activates, page reloads immediately with new version.
Browser + PWA
4b
User ignores it
Countdown ring hits zero after 10 seconds → page auto-reloads. Same result, no action needed from the user.
Browser + PWA

Before fix vs After fix

Before BUG-621 fix
Browser: silent reload with no warning
PWA: no banner, no reload — user stuck on old version
The "waiting lane" is always empty because new SW skips it instantly
Cashier gets unexpected page reload mid-order (browser)
PWA users may never know an update happened
After BUG-621 fix
Both: banner slides up showing "App updated — reloading shortly"
PWA: also shows banner when app is reopened after background update
New SW waits politely — banner check sees it immediately
Cashier can finish current action then tap Reload now
10s fallback ensures everyone gets updated even if banner is ignored
