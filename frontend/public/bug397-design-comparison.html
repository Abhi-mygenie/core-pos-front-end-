Design Agent Recommendation
Option A is recommended. It reuses the established orange = occupied signal — critical for a hotel front-desk where staff build muscle memory fast. The amber "Housekeeping in progress" line inside the tile provides the secondary signal without needing a new bar colour.

Option B (split bar) is visually clever but introduces a new pattern to the design system that no other tile uses. Option C (#EA580C) is too similar to occupied orange to be reliably distinct at a glance.
