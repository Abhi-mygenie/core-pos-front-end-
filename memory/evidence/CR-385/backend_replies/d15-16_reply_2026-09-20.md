## 2. What we fixed (D15 / D16)

After a calendar extend, sold nights are persisted on `reservation.raw_payload.pms_night_rates` as `[{date, rate, source}, ...]`.

| Call | Behavior |
|------|----------|
| Calendar **extend** | Build night ledger (held × old + CM × added); persist; return `nights_detail` |
| **Shorten** | Filter ledger to remaining nights — never use blended `rate_per_night` as unit price |
| **Same-window move** | Reuse full ledger unchanged — GST stays per-night |
| **Re-extend** | Old nights from store + CM for added; rewrite store |
| **Held** mode | Unchanged (no `nights_detail`) |

Read money from **`data.charge`**. `rate_per_night` remains the **average** (display only).
