## Observations
- Token TTL observed: a token issued ~15 min earlier returned 401 on all endpoints → short server-side session expiry (or single-active-session). Frontend 401 interceptor handles this by hard redirect to `/`.
- Unknown routes return Laravel `NotFoundHttpException` JSON with `file`, `line`, and a 24-frame `trace` (server file paths leak) → `APP_DEBUG=true` on preprod. Backend finding.
- `get-categories` and `all-table-list` (v1) return HTML with 200 when called without the exact headers the app sends → non-JSON success responses.
- v1 is **not** globally defunct: 12/14 probed v1 routes are live. Only order-family routes (`get-single-order-new`, `order-logs-report`, `pos/room-payment`) moved to v2. Corrects Sep-6 INV statement "all v1 order endpoints 404 → migrate all probes to v2".
- 403 on `get-products-list`, `cancellation-reasons`, `employee-orders-list`, `assigned-restaurants` for owner account: permission-scoped, consistent with `pos/room-payment` 403 (OG-PMS-014) — likely the sandbox owner role lacks POS permissions, not endpoint removal.
