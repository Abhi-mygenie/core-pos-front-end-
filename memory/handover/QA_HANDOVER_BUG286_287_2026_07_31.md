## 5. BUG-287 — Test Cases

**Context:** UrbanPiper sends a default placeholder `"This is order level instructions"` as `order_note` when no real note exists. After BUG-283 stripped the `"Order Instructions :::"` prefix, this placeholder remained visible. BUG-287 filters it out.

| TC# | Description | Steps | Expected |
|-----|-------------|-------|---------|
| TC-4 | Orders with placeholder note show NO note label | Open any aggregator OrderCard from Swiggy/Zomato → look for note section | If all notes are default placeholder: no "Order Notes" section visible |
| TC-5 | Orders with real note still show note | If a real note exists (e.g. "extra spicy") → open that order's card | Note label + text visible |
| TC-6 | Zomato prefix + placeholder combo stripped | Zomato order with `"Order Instructions ::: This is order level instructions"` → expand card | No note shown |
