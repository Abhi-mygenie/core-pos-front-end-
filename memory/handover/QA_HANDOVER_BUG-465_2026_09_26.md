**Zero `src/` file changes.**

**Why `>=1.48.0`** (corrected from original intake recommendation of `1.46.1`):
`recharts@3.6.0` requires `es-toolkit/compat/isPlainObject.mjs` which was introduced
in `1.47.x`. The Terser crash was caused by a CJS compat shim in `1.47.x` (issues
#1740/#1756). Fix landed in `1.48.0` (PR #1757): native ESM `.mjs` stubs for
`./compat/*` subpaths. `>=1.48.0` resolves to `1.52.0` (current latest, tested).
