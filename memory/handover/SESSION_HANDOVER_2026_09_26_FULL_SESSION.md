### 2.2 BUG-465 — Production chart crash (recharts/es-toolkit Terser minification)

**Full gate cycle completed: GATE_1 → GATE_5B QA PASS**

#### Root cause (from investigation report)
`recharts@3.6.0` uses `es-toolkit/compat/*` CJS shim. Under Webpack 5 + Terser minification (`npm run build`), the shim is mangled into a broken binding → `TypeError: mR is not a function` on first chart render. **Dev server (unminified) never crashes — bug only appears in production.**

#### Gate history

| Gate | What happened |
|---|---|
| **INTAKE (Gate 1)** | BUG-465 registered P1/HIGH/sep_bug_closure. OD-465-01 LOCKED = Option A (es-toolkit pin). OD-465-02 LOCKED = YES full regression 30 pages. OD-465-03 LOCKED = YES commit lockfile. |
| **Planning Gate 2** | Impact Analysis written — 0 src/ files, package.json only, Code Reality NONE, Conflict CLEAN. |
| **Planning Gate 3** | Implementation Plan written — E1 add overrides, clean install, `npm run build`, verify all 30 chart pages. |
| **Implementation Gate 5a — Attempt 1** | Added `"overrides": { "es-toolkit": "1.46.1" }` → **FAILED** — recharts@3.6.0 requires `isPlainObject.mjs` added in es-toolkit 1.47.x; 1.46.1 breaks the build. |
| **Implementation Gate 5a — Attempt 2** | Changed override to `>=1.48.0` (fix landed in 1.48.0 PR #1757 — native ESM .mjs stubs). Build passed locally. QA iteration_1: 7/7 PASS on production build. |
| **UAT deployment** | Fix was on `main` branch (Emergent auto-push), NOT on `21implement` branch. UAT server deploys from `21implement`. Also: deployment script clears only `node_modules/.cache`, never runs `npm install` → stale node_modules retained old es-toolkit → override had no effect. |
| **Pivot to Option 2** | Owner approved downgrade recharts `3.6.0 → 2.15.4`. recharts 2.x has **zero es-toolkit dependency** — root cause eliminated, not just worked around. |
| **Implementation Gate 5a — Final** | `recharts: 2.15.4` in package.json, overrides block removed, clean `npm install --legacy-peer-deps`, production build `main.2b8a0639.js` (exit 0, zero TypeError). |
| **QA Gate 5b** | testing_agent `iteration_2.json`: **7/7 PASS**. Zero TypeError, zero ErrorBoundary. recharts 2.15.4 confirmed working. `iteration_1.json` was earlier es-toolkit attempt. |

#### Files changed

#### Deployment instruction for UAT (`pos-uat.mygenie.online`)

```bash
cd /var/www/core-pos-front-end-/frontend

rm -rf node_modules package-lock.json
```
