## 2. Implementation Summary

### BUG-374 (P0) — Cart variation qty sync
- **Root cause:** `updateQuantity` matched by `item.id`; same-food different-variation items share `item.id`
- **Fix:** `genCartKey()` generates unique UUID per cart slot; all new cart items get `_cartKey`; `updateQuantity` unplaced path now matches by `_cartKey` (falls back to `item.id` for backward compat); CartPanel passes `item._cartKey || item.id` to all qty calls
- **Files:** `OrderEntry.jsx`, `CartPanel.jsx`

### BUG-369 — Print Customer Copy
- **Root cause:** `printBillCustomerCopy` saved in wizard but never mapped in `profileTransform` → never reached print payload
- **Fix:** Added `printBillCustomerCopy` to `profileTransform.settings()`; added flag to `CollectPaymentPanel.jsx handlePrintBill` overrides; added `print_bill_customer_copy: 'Yes'` conditionally in `orderTransform.js buildBillPrintPayload`
- **Files:** `profileTransform.js`, `CollectPaymentPanel.jsx`, `orderTransform.js`

### BUG-372 — Transfer + Merge from order card
- **Merge root cause:** `DashboardPage.jsx onMergeOrder` was `console.log` placeholder
- **Transfer root cause:** `setInitialTransferItem(item)` called AFTER `handleTableClick` (timing issue — state not set when OrderEntry mounted)
- **Fix:** Added `initialShowMerge` state; real Merge handler opens OrderEntry + sets flag; OrderEntry reads `initialShowMerge` prop and opens merge modal via useEffect; Transfer: state set BEFORE navigation
- **Files:** `DashboardPage.jsx`, `OrderEntry.jsx`

### BUG-371 — Bulk Edit variation price
- **Root cause:** `VariationExpandPanel` was read-only; `isDirty.variations = () => false`; no variation data in `buildPayload`
- **Fix:** `VariationExpandPanel` rewritten with `onPriceChange` prop + price inputs; `BulkEditor` adds `handleVariationPriceChange`; `isDirty.variations` compares against `_original.variations`; `buildPayload` includes `variation` array
- **Files:** `VariationExpandPanel.jsx`, `BulkEditor.jsx`
