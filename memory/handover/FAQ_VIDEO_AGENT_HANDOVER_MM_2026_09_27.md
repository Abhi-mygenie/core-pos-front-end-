
4. **Output per FAQ:** A sequence of 3–6 storyboard frames that, played in order, form a 30–60 second video.

## Production guidelines

**Audience:** Restaurant owners and managers — non-technical users.

**Tone:** Clear, practical, confident. No jargon. Speak to the person running the restaurant.

**Screen usage:**
- Show the primary screen for the majority of the video
- Cut to supporting screen at the moment described in the script
- Use zoom/highlight to draw attention to the specific UI element being described in each narration line
- Never show a screen that contradicts the narration

**Avoid:**
- Error toasts or "Request timed out" messages — if visible on a screen, crop or mask before use
- Real restaurant names — the screens show "Sharma Hotel & Restaurant" (a fictional name, intentional)
- Screens marked "use fallback" in the inventory above — substitute with the fallback screen noted

**Duration rule:**
- 30s FAQs: 3–4 frames max
- 45s FAQs: 4–5 frames
- 60s FAQs: 5–6 frames

**Screen notes for specific FAQs:**
- FAQ 01/02/16: Screen 41 shows Party menu is empty ("No products found") — this correctly demonstrates that the Party menu starts empty and items must be added; narration covers this
- FAQ 26/27: Use screen 43 (shows Discount + Type fields visible) — screen 42 shows the form before toggle; cut from 18 (toggle off) to 43 (toggle on) to show the transition
- FAQ 48: Use screen 45 (Add-ons panel with Edit buttons visible in ACTIONS column) — inline edit mode was not captured; the Edit button is clearly labeled and visible
- FAQ 68: Screen 38 shows the Variation Stock tab (empty state) — the UI structure is still visible; the narration explains the concept even without populated data
- FAQ 39: Show screen 22 (Full Edit Status & Flags section) as primary; use screen 44 (Quick Edit) as secondary to show the faster path

## Script file structure reminder

Each FAQ in `MM_FAQ_VIDEO_SCRIPTS_70.md` follows this format:

```
### FAQ-XX: [Question]
**Duration:** ~30s / ~45s / ~60s

**[Opening — scene description]**
Narration line...

**[Action — what happens on screen]**
Narration line...

**[Closing]**
Narration line...
```

Map each `**[...]**` label to a storyboard frame. The scene description tells you what UI state to show; the narration line is the voiceover for that frame.
