## OD-P3-02 — Arrivals tabs (Today / Upcoming / Late / Checked In)

**Accept.** Do it in the browser.

- There is **no** `checkin_date` query param. Window is only `start_date` / `end_date`.
- `page` / `per_page` are ignored.
- `view=arrivals` = pending room lines whose **checkin** falls in that window. A wide window mixes today, next week, and past-due. Client buckets are correct.

KPI tile vs list: `dashboard-kpis` `today.arrivals_count` is **as_of_date only** (usually today). It matches the **Today** tab, not Upcoming / Late.

## OD-P3-10 — Departures tabs

**Due Today default: yes.**

`view=departures` = still checked in **and** `checkout` inside `start_date`–`end_date`. A wide range includes future checkouts; Overdue / Due Today / Upcoming are client buckets.

Overdue (checkout **before** today, still in-house): set `start_date` earlier than today. We did not add a separate overdue view.

Checked Out: not this view. Use `view=all` and `operational_status=departed` / `rooms[].checked_out_at`. Sandbox still has no completed checkout sample — confirm at Gate 3.
