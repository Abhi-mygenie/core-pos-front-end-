## Findings

### F-1: TableCard S/Z Source Badge MISSING (MAJOR)

**Severity:** MAJOR
**Component:** `TableCard.jsx` (Delivery channel cards)
**Expected:** Design mockup (cr105-design-flow.html Section 3) shows orange "S" circle badge for Swiggy orders and red "Z" circle badge for Zomato orders in the card header, identical to OrderCard.
**Actual:** TableCard has NO equivalent to OrderCard's `renderLogo()` (OrderCard.jsx:353-371). Aggregator orders in the Delivery column render via TableCard (`data-testid='table-card-delivery-*'`), and their header only shows a bike icon + "Del/DEL" text + amount — no S/Z badge anywhere.
**Impact:** Users cannot distinguish Swiggy from Zomato at a glance on the dashboard grid view. This is the DEFAULT view for Delivery orders.
**Repro:** Login → Dashboard → Look at any aggregator order card in Delivery channel → No S/Z badge visible.
**Evidence:** Live DOM inspection: cards `table-card-delivery-892353`, `40474-40477` all have zero single-letter S/Z badges in DOM.

### F-2: AggregatorRejectModal Label Mismatch (MINOR)

**Severity:** MINOR
**Component:** `AggregatorRejectModal.jsx`
**Expected (mockup):** Title = "Reject Aggregator Order", Confirm button = "Confirm Reject"
**Actual:** Title = "Reject Order", Confirm button = "Reject Order"
**Evidence:** Code review of AggregatorRejectModal.jsx

### F-3: AggregatorDispatchModal Label Mismatch (MINOR)

**Severity:** MINOR
**Component:** `AggregatorDispatchModal.jsx`
**Expected (mockup):** Confirm button = "Confirm Dispatch"
**Actual:** Confirm button = "Dispatch"
**Evidence:** Code review of AggregatorDispatchModal.jsx
