## GAPS — Full List

### GAP-1 (MINOR) — Rate grid cells not reachable by automation
**Type:** Automation coverage gap
**Detail:** Custom React rate cells render ₹ values but have no `role` or accessible name that Playwright can target. Standard `click()` calls do not trigger the cell popover.
**Impact:** T3/T4/T5/T6 (stage flow + diff modal) could not be executed via automation.
**Recommendation:** Manual QA: click a cell → verify popover → stage → review modal → discard. OR add `aria-label` to cells.
**Blocks Gate 6?** NO — visual confirmation of cell rendering + correct ₹ values from real preprod data is strong evidence. Interactive flow needs manual owner smoke.
