| # | Limitation | Impact | Resolution |

| ENV-1 | **palmhouse has null `crm_token`** — login response returns `crm_token: null` | All CRM features (typeahead search, B2B auto-populate, CRM B2B sync) silently no-op in browser | Provision CRM API key for palmhouse tenant in CRM system |
| ENV-2 | **palmhouse has `booking_details=false`** — restaurant profile flag disables Booking Details section | Cannot test Corporate/Individual toggle, GST block, or G3 CRM B2B sync in browser | Enable `booking_details` flag in palmhouse restaurant settings via backend |
| ENV-3 | **No test tenant has both rooms + CRM token** — palmhouse has rooms but no CRM; kunafamahal has CRM but no rooms | Cannot do full E2E browser test of G3/G4 on any single tenant | Either add CRM to palmhouse or add rooms to kunafamahal |
