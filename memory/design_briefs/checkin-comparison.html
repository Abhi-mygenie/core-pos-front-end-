Changes in this design
  • Fixed Phone: removed globe + dropdown entirely. Fixed "+91" badge on left. Receptionist types 10 digits, done.
  • Fixed File upload: real thumbnail preview at ID card ratio (1.58:1). X button to remove and re-upload.
  • New "Documents on File" section: CRM thumbnails with green Verified badge for returning guests. Receptionist knows instantly — don't ask for ID again.
  • UX Optional fields labelled "(optional)" so receptionist doesn't pause. Focus rings on active inputs. Booking section has subtle background tint to chunk the form visually.
  • UX Check-In button has scale press animation for tactile feedback.
Design reference only — no code changes. Ready for implementation once design is approved.
