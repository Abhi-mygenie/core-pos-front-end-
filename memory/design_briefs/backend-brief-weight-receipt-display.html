Conversion Rule
Condition Display QTY As Display PRICE As Example
item_unit = "Kg" AND quantity < 1 quantity × 1000 gm unit_price/Kg 0.5Kg → 500gm, ₹830/Kg
item_unit = "Kg" AND quantity ≥ 1 quantity Kg (no change) unit_price/Kg 2Kg → 2Kg, ₹600/Kg
item_unit = "L" AND quantity < 1 quantity × 1000 ml unit_price/L 0.25L → 250ml, ₹200/L
item_unit = "L" AND quantity ≥ 1 quantity L (no change) unit_price/L 2L → 2L, ₹200/L
item_unit = "gm" quantity gm (no change) unit_price/gm 100gm → 100gm, ₹10/gm
item_unit = "ml" quantity ml (no change) unit_price/ml 250ml → 250ml, ₹5/ml
Recommended Fix — Receipt/KOT Print Template

Add this logic wherever quantity + unit are formatted for the printed receipt:

// Smart weight display for receipt/KOT if ($item->item_unit === 'Kg' && $item->quantity < 1) { $displayQty = round($item->quantity * 1000) . 'gm'; $displayPrice = $item->unit_price . '/Kg'; } elseif ($item->item_unit === 'L' && $item->quantity < 1) { $displayQty = round($item->quantity * 1000) . 'ml'; $displayPrice = $item->unit_price . '/L'; } else { $displayQty = $item->quantity . $item->item_unit; $displayPrice = $item->unit_price; } // Use $displayQty and $displayPrice in the receipt row

Questions for Backend Team
Q1: Where does the receipt template live?

Is it in the Laravel backend (Blade/PHP) or in the printer agent (native desktop app)? This determines where the fix goes.

Q2: Should "/Kg" suffix show in the PRICE column?

Current: PRICE shows just the number (830). Proposed: show "830/Kg" for clarity. Is there space on the receipt for the suffix?

Q3: Items configured as "gm" unit — show per-gm or convert to per-Kg?

Some items are configured as gm with ₹10/gm (= ₹10,000/Kg). Should receipt show "₹10/gm" or convert to "₹10,000/Kg"? Recommend: show as-is (₹10/gm) since that's what's configured.
