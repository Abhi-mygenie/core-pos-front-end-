BUG-315  ·  Numeric Inputs — Cannot Clear to Retype
P2 · LOW · Affects Bill Copies, KOT Copies, and all font size inputs in Print Style.
❌ BEFORE — "1" snaps back when you try to delete it
Bill Copies — try to change 1 → 3
1. Shows "1" → 2. Press Delete ⚡ Snaps back to 1
Root cause: React controlled input — when cleared, onChange returns early without updating state → React resets to old value on next render. User cannot clear to type a new number.
✅ AFTER — Clear field, type new number freely
Bill Copies — change 1 → 3
1. Shows "1" → 2. Press Delete → 3. Type "3" ✓ Works
On blur without typing → clamps to minimum (1). Same fix applies to all font size inputs in Print Style tab.
