7 Edge Cases

🍴 Addons
Order #002388: sahi paneer ×4 + cheese addon.
FE sent vat_tax=11.68. Backend doesn't return it. FE recomputes on base 92 → 3.68 (wrong).
🍴 Variations
Item with +₹20 "large" upcharge. Same gap — FE computes tax on base without variation upcharge.
💰 Mixed GST + VAT
Item A: GST 18%, Item B: VAT 5%. FE sent both separately. Backend must return both so FE doesn't need to split.
✏️ After Edit
Place → vat_tax=10. Edit (add items) → vat_tax=15. Socket update returns: vat_tax=❌. Updated value lost.
🚚 Delivery
delivery_charge_gst_amount sent by FE but not returned. Print needs it for correct total.
🏩 Room Orders
Room with associated table orders. Tax gap same as dine-in. Associated amounts correct, but tax is wrong.
💳 Discount
Manual print happens BEFORE collect bill (no discount yet). Pre-discount tax from place-order should be returned as-is.
