3 — Row State Guide
No entry (default)
Input shows "—" placeholder. Row is white. No wastage dropdown. Save button not counting this row.
Positive drift (stock added)
New qty > current. Row tinted green. Green "+X.XX kg" badge. Wastage N/A (disabled). Batch/Expiry optional.
Negative drift (wastage)
New qty < current. Row tinted amber. Amber "−X.XX kg preview" badge. Wastage reason dropdown REQUIRED — red border until selected. Save blocked if empty.
