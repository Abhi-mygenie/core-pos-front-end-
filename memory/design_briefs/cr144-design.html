What is CR-144?

Add a full Addon Master panel inside the existing Menu Management slide-over. Manage all restaurant addons (add / edit / delete / toggle active) from one place, visible for all menu types.

Where does it live?

A new "Add-ons" button in the Menu Management header — sits next to the existing "Bulk Edit" button. Clicking it switches the panel to Addon Master view. No new route, no new page.

Why no design study needed?

Unlike CR-145 (BulkEditor — 5 UX unknowns), CR-144's design was fully specified in the intake doc. Both OQs were minor and adopted as defaults. No owner decision was blocked.

What this panel does

  • List all restaurant addons (veg dot + weight + stock + inventory)
  • Add new addon (name, price, weight, veg type)
  • Edit existing addon inline (click Edit → row expands)
  • Toggle active/inactive per addon
  • Delete addon (with confirm dialog)
  • Search/filter by name

What it does NOT do (out of scope)

  • No food-level addon assignment here (that's ProductForm)
  • No aggregator-specific scoping (addons are restaurant-wide)
  • No bulk addon operations
  • Inventory toggle gated by "has recipe" — no recipe = disabled
  • No separate page or route added
