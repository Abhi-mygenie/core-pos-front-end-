⚠
BUG-580 — Discount types missing (Thrive, custom types)

orders_table[].discount_for is the sole source of discount type labels in the UI. If backend does not include entries for custom discount types like "Thrive" in orders_table[], those discount types will not appear anywhere in the Discount Report. Backend must populate discount_for for ALL discount types applied to an order. Also confirm: is "Thrive discount" included in summary.manual_discount or tracked under a separate field?
